# Security Policy

## Reporting a Vulnerability

Contact the security team at security@appgate.io. Do not file public GitHub issues for security vulnerabilities. Expect acknowledgment within 24 hours.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅        |

## Security Requirements

All contributions must comply with:
1. Zero Trust Architecture
2. Least Privilege Principle
3. Defense in Depth
4. Fail Closed
5. Secure Defaults
6. Explicit Authorization
7. Short-lived Credentials
8. Strong Service Identity
9. Immutable Infrastructure
10. No Secrets in Git
